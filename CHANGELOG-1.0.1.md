# CoBrowser 1.0.1

- Corrected the product version from the mistakenly assigned 1.6.4 to 1.0.1.
- Refined the unified Chrome + Microsoft Bing visual direction.
- Added persistent System, Light and Dark appearance modes. System mode follows Windows appearance changes.
- Set Bing as the default search provider and added a menu option to switch between Bing and Google.
- Preserved the existing Chromium browser functionality and separate Windows portable/installer build outputs.
